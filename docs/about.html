The pipeline

Every 6 hours a GitHub Actions job runs this pipeline on a free CPU machine. The site you're reading is a static page that loads the results.

  1. 1
    Fetch

    About 300 new items from 14 sources: OpenAI, DeepMind, Google AI, Microsoft Research, NVIDIA, Hugging Face, BAIR, TechCrunch, The Verge, MIT Tech Review, Ars Technica, arXiv, HF Daily Papers, Hacker News

  2. 2
    Fuzzy dedupe

    Drops stories already seen and near-identical titles (RapidFuzz string matching).

  3. 3
    Semantic dedupe Encoder

    MiniLM turns each story into a 384-number meaning vector. If it's ≥ 0.80 similar to an existing card, it's the same story in other words → dropped.

  4. 4
    Predict importance Feedforward network

    An MLP trained on ~1,000 past cards guesses each story's stars and category before any LLM call, and ranking uses it to choose the best 40.

  5. 5
    Write the card LLM · decoder

    gpt-oss-120b (via Groq) writes the headline, TL;DR, key points, why it matters, category and stars as strict JSON. It falls back to other models and Gemini on errors.

  6. 6
    Related cards + search index Encoder

    New cards are embedded. The 4 nearest neighbours become "Related stories", and the vectors power search by meaning in your browser.

  7. 7
    Cover images Diffusion

    A follow-up job runs SD-Turbo (one-step Stable Diffusion) on CPU to illustrate the most important new cards.

  8. ★
    Weekly model comparison Local decoder

    Two small open models (Qwen2.5 0.5B and 1.5B) run locally on the same inputs, and we measure how close each gets to the 120B API model.

Same story, three decoders

Identical prompt and input. The 120B model the site uses, next to two small open models (0.5B and 1.5B parameters) running on a free CPU, so you can see how quality grows with model size.

Colours

The accent and category colours are exact colours from Sanzo Wada's A Dictionary of Color Combinations (1933–34), a classic Japanese study of colour harmony, using the values published at wada-sanzo-colors.com. The "Tokyo neon" theme uses his brightest inks (Peach Red, Yellow, Sea Green, Calamine Blue) on near-black; light mode uses his deeper tones on white. Every colour was checked for WCAG AA contrast.

Stack & cost

Python · feedparser · RapidFuzz · fastembed (ONNX) · scikit-learn · Groq / Gemini APIs · diffusers · transformers · GitHub Actions (scheduler) · GitHub Pages (hosting) · vanilla JS + transformers.js. Total cost: $0. Everything runs on free tiers.
